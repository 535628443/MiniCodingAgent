# Agent Builder Skill

Guidelines for building autonomous AI agents:
1. Define minimal and orthogonal tool schemas.
2. Implement human-in-the-loop permission checks and safety hooks.
3. Manage conversation context length with two-level knowledge injection or subagents.
4. Enforce task management and progress tracking with structured todo lists.
